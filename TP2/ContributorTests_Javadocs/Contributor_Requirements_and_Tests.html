TP2 Contributor Requirements and Tests (Tasks 6 and 7.1)

Every Contributor (Phase Two) requirement from the 2026-08-19 user stories, with its owner and two or more tests, at least one positive and one negative. C1-C4 are the four Contributor Phase Two stories in order. This page is generated from ContributorRequirement and the @RequirementTest annotations in ContributorRequirementsTestbed, so it always matches the code.

18 requirements, 50 tests (20 positive, 30 negative). Run the tests: in Eclipse run testingAutomation.ContributorRequirementsTestbed, or from the TP2 folder run python3 dev.py test to run this testbed and every other team suite. Actual output: testbed output.

Each test link opens its Javadoc (requirement tested, how it is checked, how to read the output); each .png link opens the screenshot of that test's code and comments. See also the test Javadoc template, the manual tests, and the full test Javadoc including every teammate's test classes.
