TP2 Contributor Manual Tests

One manual procedure per Contributor requirement, run through the real GUI. Use the isolated demo database: from the TP2 folder run python3 dev.py demo, which creates Contributor accounts jsmith, akim and newcontributor and seeds unlocked, field-locked, whole-locked and curator-edited lessons (the demo-only password is printed on the first run and is listed in README_VISHWAM_TP2.md). Delete data/TP2Demo.mv.db to start fresh. Record Pass/Fail, the tester, and the date in the last two columns; the columns are blank until a person runs the procedure.

Every requirement is also checked automatically; see requirements and tests.
